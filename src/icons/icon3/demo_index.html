Unicode 引用

Unicode 是字體在網頁端原始的應用方式，特點是：

  • 支持按字體是方式去動態調整圖標大小，顏色等等。
  • 默認情況下不支持多色，直接添加多色圖標會自動去色。

注意：新版 iconfont 支持兩種方式引用多色圖標：SVG symbol 引用方式和彩色字體圖標模式。（使用彩色字體圖標需要在「編輯項目」中開啟「彩色」選項後並重新產生。）

Unicode 使用步驟如下：

第一步：拷貝項目下面產生的 @font-face

@font-face {
  font-family: 'iconfont';
  src: url('iconfont.woff2?t=1644560342859') format('woff2'),
       url('iconfont.woff?t=1644560342859') format('woff'),
       url('iconfont.ttf?t=1644560342859') format('truetype');
}

第二步：建議使用 iconfont 的樣式

.iconfont {
  font-family: "iconfont" !important;
  font-size: 16px;
  font-style: normal;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

第三步：挑選相應圖標並獲取字體編碼，應用於頁面

<span class="iconfont">&#x33;</span>

"iconfont" 是你項目下的 font-family。可以通过編輯項目查看，默認是 "iconfont"。

font-class 引用

font-class 是 Unicode 使用方式的變種，主要是解決 Unicode 書寫不直觀，語意不明確的問題。

与 Unicode 使用方式相比，具有以下特點：

  • 相較於 Unicode 語意明確，書寫較直觀。可以很容易分辨這個 icon 是什麼。
  • 因為使用 class 來定義圖標，所以當要取代圖標時，只需要修改 class 裡面的 Unicode 參考。

使用步驟如下：

第一步：引入專案下面產生的 fontclass 程式碼：

<link rel="stylesheet" href="./iconfont.css">

第二步：挑選對應圖示並取得類別名，套用至頁面：

<span class="iconfont el-icon-thirdxxx"></span>

" iconfont" 是你專案下的 font-family。可以透過編輯項目查看，預設是 "iconfont"。

Symbol 引用

這是一種全新的使用方式，應該說這才是未來的主流，也是平台目前推薦的用法。相關介紹可以參考這篇文章 這種用法其實是做了一個 SVG 的集合，與另外兩種相比有以下特點：

  • 支援多色圖示了，不再受單色限制。
  • 透過一些技巧，支援像字體那樣，透過 font-size, color 來調整樣式。
  • 相容性較差，支援 IE9+，及現代瀏覽器。
  • 瀏覽器渲染 SVG 的效能一般，還不如 png。

使用步驟如下：

第一步：引入專案下面產生的 symbol 程式碼：

<script src="./iconfont.js"></script>

第二步：加入通用 CSS 程式碼（引入一次就行）：

<style>
.icon {
  width: 1em;
  height: 1em;
  vertical-align: -0.15em;
  fill: currentColor;
  overflow: hidden;
}
</style>

第三步：挑選對應圖示並取得類別名，套用於頁面：

<svg class="icon" aria-hidden="true">
  <use xlink:href="#icon-xxx"></use>
</svg>
